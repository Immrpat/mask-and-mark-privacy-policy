# Mask & Mark privacy policy

Public privacy policy for **Mask & Mark: PDF Redactor**, an Android app published by **Namib** (`com.safedocument.app`).

**Website:** https://immrpat.github.io/mask-and-mark-privacy-policy/

**Privacy contact:** pat@namibapp.com

This repository contains only the policy website and its brand mark. It does not contain the Android application, documents, signing material or credentials.

## Preview and update

No build system or dependencies are required. Serve this directory locally with `python3 -m http.server 8080 --bind 127.0.0.1` and open http://127.0.0.1:8080/.

Edit `index.html` and `styles.css`, update the policy date when practices change, verify the live app's data handling and SDK disclosures, then commit and push to `main`. GitHub Pages publishes the root of `main`. Keep the publisher and public contact accurate. Do not add tracking or document-upload functionality without revising the policy and app disclosures.

This page describes local editable documents and signatures, generated exports, user-selected sharing destinations, Google AdMob and UMP, retention and deletion, and GitHub Pages hosting. It must be reviewed when any of those practices change. A published page does not itself complete Play Console Data safety or AdMob consent configuration.
